# Get It Done! ✅

A clean, minimal todo app built with React and Tailwind CSS.

## Features

- ✅ Add, complete, and delete todos
- ✏️ Double-click any todo to edit it
- 💾 Persists data in localStorage — todos survive page refresh
- 📱 Fully responsive — works on mobile and desktop
- 🎨 Glassmorphism UI with dark gradient background

## Tech Stack

- React (Vite)
- Tailwind CSS
- localStorage for persistence

## Getting Started

```bash
git clone https://github.com/Harish115-dev/todo-web-app.git
cd get-it-done
npm install
npm run dev
```

## Usage

| Action | How |
|---|---|
| Add todo | Type in input (min 4 chars) → click **Add this** |
| Complete todo | Click the ✅ check button |
| Delete todo | Click the 🗑️ delete button |
| Edit todo | Double-click the todo text |
